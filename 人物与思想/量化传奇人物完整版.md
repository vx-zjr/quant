## 一、国际量化传奇

### Jim Simons 西蒙斯

| 项目 | 内容 |
|------|------|
| 机构 | Renaissance Technologies |
| 基金 | Medallion Fund (大奖章基金) |
| 成就 | 年化66%，1988-2018年最佳对冲基金 |
| 背景 | 数学家，菲尔兹奖得主 |
| 方法 | 纯量化，数学模型 |
| 教育 | MIT数学博士 |

### 背景介绍

Jim Simons（1938-2010）是量化投资之父，数学界的传奇人物。他曾是威廉姆斯学院的数学系主任，与陈省身共同创立了陈省身-西蒙斯理论，在拓扑学和几何学领域有重大贡献。1978年创立Renaissance Technologies，开创量化投资时代。

### 投资哲学

1. **市场存在无效性**：相信市场存在短期无效，可以通过数学模型捕获
2. **数据驱动**：海量数据分析，发现统计规律
3. **短期交易**：持仓周期短，从分钟到几天不等
4. **高度保密**：策略严格保密，员工禁止对外讨论

### 经典语录

> 找到市场中存在的无效性，然后用数学模型去捕获它。

> 我没有用过任何基本面分析，全靠数学模型。我坚信市场是有规律的，而数学可以帮助我们发现这些规律。

### David Shaw 德邵

| 项目 | 内容 |
|------|------|
| 机构 | D.E. Shaw |
| 成就 | 华尔街量化先驱 |
| 背景 | 计算机科学家 |
| 方法 | 学术驱动，跨学科研究 |

### 背景介绍

David Shaw于1988年创立D.E. Shaw，他是计算机科学背景，博士学位来自NYU Courant Institute。他将学术研究方法引入量化投资，创造了华尔街最早的量化对冲基金之一。

### 投资哲学

1. **学术驱动**：以严谨的学术研究方法开发策略
2. **跨学科融合**：数学、计算机、统计多学科交叉
3. **人才为本**：大量聘用PhD人才
4. **技术基础设施**：强大的技术平台支撑

|------|------|
| 机构 | Two Sigma |
| 职位 | Co-Founder and Co-CEO |
| 背景 | Amazon推荐系统专家 |

1. **数据科学**：将机器学习和大数据分析应用于投资
2. **规模化研究**：系统化的投研流程
3. **技术创新**：持续的技术投入

### Ken Griffin

| 项目 | 内容 |
|------|------|
| 机构 | Citadel |
| 成就 | 华尔街最成功的做市商 |
| 背景 | 自营交易起家 |
| 方法 | 做市+量化 |

### 背景介绍

Ken Griffin于1990年创立Citadel，从自营交易起步，发展成为全球最大的对冲基金之一。他的Citadel Securities是美国最大的做市商之一，处理超过25%的美股交易量。

### 投资哲学

1. **做市为核心**：通过做市获取稳定收益
2. **技术领先**：自研低延迟交易系统
3. **规模优势**：规模效应降低边际成本

### Edward Thorp 爱德华·索普

| 项目 | 内容 |
|------|------|
| 成就 | 21点必胜策略 |
| 背景 | 数学教授 |
| 方法 | 凯利公式 |

### 背景介绍

Edward Thorp是量化投资的先驱之一，他是MIT数学教授，出版了《Beat the Dealer》，证明了21点可以被打败。他还与Claude Shannon一起发明了第一个可穿戴电脑。

### 代表著作

- 《Beat the Dealer》- 21点制胜策略
- 《Beat the Market》- 市场制胜策略

### 经典语录

> 投资的核心是管理概率，你需要让赢面站在你这边。

### 背景介绍

梁文锋是幻方量化的创始人，浙江大学背景，技术导向型人才。他是DeepSeek的创始人，将AI大模型技术引入量化投资领域。

### 投资哲学

1. **AI赋能量化**：用AI大模型驱动因子发现和策略研发
2. **算力为王**：自建超算中心，万卡级别GPU集群
3. **技术创新**：持续投入新技术，保持领先地位
4. **自动化**：因子挖掘自动化，减少人工干预

### 核心理念

- 幻方的萤火虫系统是自研AI量化投研平台
- DeepSeek是幻方关联的AI大模型
- 技术创新是核心竞争力

## 四、投资哲学与核心理念

### 量化优势

| 优势 | 说明 |
|------|------|
| 纪律性 | 严格执行策略，避免人为干扰 |
| 可复制性 | 策略可规模化复制 |
| 可回测 | 历史数据验证策略有效性 |
| 情绪稳定 | 不受情绪影响决策 |

### 量化局限

| 局限 | 说明 |
|------|------|
| 模型风险 | 模型可能失效 |
| 过度拟合 | 历史数据过度拟合 |
| 市场适应性 | 策略可能不适应市场变化 |
