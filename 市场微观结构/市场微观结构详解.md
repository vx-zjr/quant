## 一、理论基础：核心模型

### 1.1 信息不对称与知情交易者

市场微观结构理论的核心问题是：给定交易者的信息不对称，价格如何形成？

- **信息不对称**：不同交易者拥有不同的私有信息
- **逆向选择**：知情交易者利用信息优势获利
- **指令流毒性**：订单流携带未来价格信息

### 1.2 Glosten-Milgrom模型(1985)

**知情交易者模型**：做市商根据订单流设定价格

- P_bid = E[V|buy] = 知情概率调整后的价值
- P_ask = E[V|sell] = 知情概率调整后的价值

**关键结论**：
- 买卖价差包含信息成本
- 做市商通过价差补偿被知情交易者套利的风险

### 1.3 Kyle模型(1985)

**批量竞价模型**：价格冲击与订单流成正比

p = mu + lambda * y

其中：lambda = sigma_V / sigma_U 是价格冲击系数

**关键结论**：
- 知情交易者倾向于隐藏大单
- 订单流不平衡可预测价格变动

### 1.4 Roll模型(1984)

**有效价差估计**：c = 2 * sqrt(-Cov(dP_t, dP_t-1))

当协方差为负时，估计有效价差。

## 二、订单簿结构与动力学

### 2.1 订单簿基础结构

**订单簿(Order Book)** 是买卖盘口的集合：

| 方向 | 说明 | 价格特征 |
|------|------|----------|
| **Bid(买盘)** | 买方愿意支付的最高价 | 价格递减排列 |
| **Ask(卖盘)** | 卖方愿意接受的最低价 | 价格递增排列 |

### 2.2 关键指标计算

| 指标 | 计算公式 | 含义 |
|------|----------|------|
| **买卖价差(Spread)** | S = P_ask - P_bid | 交易成本 |
| **中间价(Mid)** | M = (P_bid + P_ask) / 2 | 市场参考价 |
| **相对价差** | RS = (S/M) x 10000 bps | 标准化的交易成本 |
| **订单簿深度** | D = Q_bid + Q_ask | 支撑阻力强度 |

### 2.3 订单簿不平衡度(OI)

OI = (V_bid - V_ask) / (V_bid + V_ask)

- **OI > 0**：买盘力量强，价格可能上涨
- **OI < 0**：卖盘力量强，价格可能下跌
- **OI 接近 0**：市场相对平衡

### 2.4 价格冲击估计

假设以市价单买入Q股，估计执行价格：

1. 从最优卖价开始，逐档计算
2. 累加订单簿数量直到完成交易量
3. 计算加权平均执行价

### 2.5 订单簿动力学

订单簿随时间动态变化：

| 事件 | 影响 |
|------|------|
| **订单到达** | 新增订单，增加深度 |
| **订单取消** | 减少订单簿数量 |
| **订单修改** | 调整订单数量 |
| **成交** | 同时减少双方数量 |

## 三、高频数据结构与处理

### 3.1 数据类型详解

| 数据类型 | 频率 | 内容 | 应用 |
|----------|------|------|------|
| **Level-1** | 秒级 | 买卖一价、成交量 | 基础分析 |
| **Level-2** | 秒级 | 5档/10档/50档 | 订单簿分析 |
| **Tick(逐笔)** | 微秒级 | 每笔成交 | 高频策略 |
| **Order Update** | 微秒级 | 委托变化 | 订单流分析 |

### 3.2 Level-2数据结构

- timestamp: 时间戳(纳秒)
- symbol: 股票代码
- bids: 买盘 [(price, qty), ...]
- asks: 卖盘 [(price, qty), ...]
- last_price: 最新成交价
- total_volume: 成交量

### 3.3 逐笔成交数据结构

- time: 成交时间
- price: 成交价
- volume: 成交量
- direction: 主动买入/卖出
- order_id: 订单号

### 3.4 订单簿重建

从逐笔成交和委托变化消息重建完整订单簿：

| 消息类型 | 说明 |
|----------|------|
| **Add** | 添加新订单 |
| **Modify** | 修改订单数量 |
| **Cancel** | 取消订单 |
| **Trade** | 成交(减少订单簿数量) |
| **Snapshot** | 全量快照(重置订单簿) |

### 3.5 高频数据存储

| 数据库 | 适用场景 | 特点 |
|--------|----------|------|
| **KDB+** | 高频数据 | 高性能时序 |

## 四、流动性与市场质量

### 4.1 流动性度量指标

| 指标 | 计算公式 | 含义 |
|------|----------|------|
| **价差(Spread)** | S = P_ask - P_bid | 交易成本 |
| **相对价差** | RS = (S/M) x 10000 | 标准化的交易成本(bps) |
| **Amihud非流动性** | ILL = |R|/Volume | 价格对成交量的敏感度 |
| **市场深度** | MD = sum(Q_bid,i + Q_ask,i) | 支撑/阻力强度 |
| **弹性(Resiliency)** | 价格冲击后恢复速度 | 流动性恢复能力 |

### 4.2 Amihud非流动性指标

ILL_t = |R_t| / Volume_t

- 值越大表示流动性越差
- 用于衡量股票流动性风险
- 与预期收益呈正相关

### 4.3 Roll有效价差

c = 2 * sqrt(-Cov(dP_t, dP_t-1))

当协方差为负时，估计有效价差。

### 4.4 Pastor-Stambaugh流动性因子

r_t+1 = theta + phi * sign(r_t) * |r_t|/Volume_t + epsilon

phi 即为流动性代理因子。

### 4.5 流动性风险

**流动性枯竭的表现**：
- 价差急剧扩大
- 市场深度骤降
- 价格冲击放大

**风险管理建议**：
- 设置流动性阈值预警
- 限制单笔交易规模
- 准备应急平仓策略

## 五、交易成本分析(TCA)

### 5.1 成本构成

| 类型 | 描述 | 计算 |
|------|------|------|
| **佣金** | 交易所/券商收费 | 固定费率 |
| **印花税** | 仅卖出收取 | 千分之一(A股) |
| **过户费** | 登记结算费 | 万分之0.2 |
| **价差成本** | 买入相对于中间价 | (P_exec - P_mid) x Q |
| **市场冲击** | 大单对价格的影响 | 非线性函数 |
| **延迟成本** | 等待执行的价差损失 | sigma * sqrt(t) |
| **机会成本** | 未成交的潜在损失 | 取决于策略 |

### 5.2 实施差距(IS)

IS = (P_exec - P_decision) / P_decision

衡量执行价格与决策时价格的差异。

### 5.3 有效价差

ES = 2 * |P_exec - M| / M * 10000

以基点(BPS)表示，方便跨市场比较。

### 5.4 市场冲击模型

**平方根法则**：

MI = sigma * sqrt(Q / ADV)

- Q: 交易量
- ADV: 平均日成交量
- sigma: 波动率

### 5.5 TCA报告指标

| 指标 | 说明 | 优化方向 |
|------|------|----------|
| **实施差距** | IS值 | 越小越好 |
| **有效价差** | ES值 | 越小越好 |
| **冲击成本** | MI值 | 越小越好 |
| **达成率** | 成交比例 | 越高越好 |
| **VWAP偏差** | 偏离VWAP | 越小越好 |

## 六、最优执行策略

### 6.1 Almgren-Chriss模型

**目标函数**：min E[C] + lambda * Var[C]
执行成本 + 风险成本

**解析解**：最优执行路径满足指数衰减

kappa = sqrt(lambda * gamma / eta)

- eta: 临时性冲击系数
- gamma: 永久性冲击系数

### 6.2 VWAP算法

**成交量加权平均价格**：
- 基于历史成交量分布计划交易
- 适应市场成交量波动调整

Q_t = (V_t / sum(V)) * N

- Q_t: 时间段t的交易量
- V_t: 预期成交量
- N: 总股数

### 6.3 IS算法(Implementation Shortfall)

**特点**：
- 根据紧急程度调整执行速度
- 紧急度高则快速执行
- 紧急度低则慢速执行以降低冲击

urgency = (1-alpha) * urgency_vol + alpha * urgency_urgent

### 6.4 TWAP算法

**时间加权平均价格**：
- 平均分配交易量到时间窗口
- 简单但不考虑市场状态

### 6.5 执行算法对比

| 算法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **VWAP** | 降低冲击 | 预测依赖 | 大宗交易 |
| **TWAP** | 简单 | 容易被识别 | 流动性好 |
| **IS** | 最优化成本 | 参数敏感 | 主动执行 |
| **AC** | 风险控制 | 计算复杂 | 风险厌恶 |

## 八、实战工具与代码实现

### 8.1 订单簿分析器

```python
import numpy as np
from collections import deque

class OrderBook:
    def __init__(self):
        self.bids = []  # [(price, qty), ...]
        self.asks = []

    def best_bid_ask(self):
        bid = self.bids[0][0] if self.bids else 0
        ask = self.asks[0][0] if self.asks else 0
        return bid, ask

    def spread(self):
        bid, ask = self.best_bid_ask()
        return ask - bid

    def mid_price(self):
        bid, ask = self.best_bid_ask()
        return (bid + ask) / 2

    def imbalance(self, levels=10):
        bid_vol = sum(q for p, q in self.bids[:levels])
        ask_vol = sum(q for p, q in self.asks[:levels])
        total = bid_vol + ask_vol
        return (bid_vol - ask_vol) / total if total else 0

    def estimate_impact(self, side, quantity):
        levels = self.asks if side == "buy" else self.bids
        remaining = quantity
        cost = 0
        for price, qty in levels:
            trade = min(qty, remaining)
            cost += trade * price
            remaining -= trade
            if remaining <= 0: break
        return cost / (quantity - remaining) if quantity > remaining else 0
```

### 8.2 Tick处理器

```python
from collections import deque
import numpy as np

class TickProcessor:
    def __init__(self, window=100):
        self.buffer = deque(maxlen=window)
        self.buy_vol = 0
        self.sell_vol = 0

    def process(self, tick):
        self.buffer.append(tick)
        if tick["dir"] == "buy":
            self.buy_vol += tick["vol"]
        else:
            self.sell_vol += tick["vol"]

    def trade_imbalance(self):
        total = self.buy_vol + self.sell_vol
        return (self.buy_vol - self.sell_vol) / total if total else 0

    def vwap(self):
        if not self.buffer: return 0
        prices = [t["price"] for t in self.buffer]
        vols = [t["vol"] for t in self.buffer]
        return np.average(prices, weights=vols)
```

### 8.5 高频数据回放引擎

```python
import time

class TickReplayEngine:
    def __init__(self, ticks):
        self.ticks = ticks
        self.index = 0

    def __iter__(self): return self

    def __next__(self):
        if self.index >= len(self.ticks):
            raise StopIteration
        tick = self.ticks[self.index]
        self.index += 1
        return tick

    def replay_at_speed(self, speed=1.0, callback=None):
        start_time = None
        for tick in self:
            if start_time is None: start_time = tick["time"]
            target = start_time + (tick["time"] - start_time) / speed
            while time.time() < target: time.sleep(0.0001)
            if callback: callback(tick)
```

### 8.6 微结构信号生成

```python
from collections import deque

class MicrostructureSignals:
    def __init__(self):
        self.spreads = deque(maxlen=100)
        self.depths = deque(maxlen=100)

    def calc_oi(self, book, levels=5):
        bid_vol = sum(q for p, q in book.bids[:levels])
        ask_vol = sum(q for p, q in book.asks[:levels])
        total = bid_vol + ask_vol
        return (bid_vol - ask_vol) / total if total else 0

    def calc_ti(self, trades):
        buy = sum(t["vol"] for t in trades if t["dir"]=="buy")
        sell = sum(t["vol"] for t in trades if t["dir"]=="sell")
        total = buy + sell
        return (buy - sell) / total if total else 0

    def signal(self, book, trades):
        oi = self.calc_oi(book)
        ti = self.calc_ti(trades[-100:])
        score = 0.4 * oi + 0.4 * ti
        if score > 0.3: return "buy"
        if score < -0.3: return "sell"
        return "neutral"
```
