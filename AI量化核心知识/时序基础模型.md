# 时序基础模型(Time Series Foundation Models)

## 一、概述

时序基础模型是大规模预训练的时间序列模型，能够处理多种时序预测任务，代表了AI量化的新方向。

### 主要模型
| 模型 | 开发方 | 特点 |
|------|--------|------|
| TimeGPT | Nixtla | 首个时序基础模型 |
| Chronos | Amazon | 预训练时序模型 |
| Lag-Llama | 社区 | 开源时序模型 |
| Moirai | Sony | 多模态时序 |
| UniTS | 社区 | 统一时序模型 |

---

## 二、TimeGPT

### 简介
- **开发方**: Nixtla
- **特点**: 首个商业化时序基础模型
- **训练数据**: 1000亿+时序数据点

### 技术特点
1. **大规模预训练**: 基于海量时序数据
2. **少样本预测**: 少量数据即可预测
3. **不确定性量化**: 提供预测区间

### 应用场景
```python
# TimeGPT使用示例
from nixtlats.timegpt import TimeGPT

# 初始化
timegpt = TimeGPT(token='your-token')

# 预测
forecast = timegpt.plot(
    df, 
    freq='H',  # 小时数据
    forecast_length=24  # 预测24小时
)
```

## 五、时序基础模型在量化中的应用

### 应用方向
| 应用 | 描述 |
|------|------|
| 价格预测 | 股票、期货价格预测 |
| 波动率预测 | 实现波动率估计 |
| 风险预测 | VaR/CVaR预测 |
| 因子预测 | 另类因子预测 |

### 代码示例：量化预测
```python
import pandas as pd
import numpy as np

# 使用Chronos进行股价预测
def stock_price_forecast(prices, model, prediction_days=5):
    """
    使用时序基础模型预测股价
    
    参数:
    prices: 历史价格序列
    model: 时序模型
    prediction_days: 预测天数
    """
    # 准备数据
    context = prices.values[-336:]  # 最近14天(分钟数据)
    
    # 预测
    forecast = model.predict(
        context, 
        prediction_length=prediction_days * 390  # 每日390分钟
    )
    
    # 提取点预测和置信区间
    mean_forecast = forecast.mean(axis=0)
    lower_bound = np.percentile(forecast, 5, axis=0)
    upper_bound = np.percentile(forecast, 95, axis=0)
    
    return {
        'mean': mean_forecast,
        'lower': lower_bound,
        'upper': upper_bound
    }

# 波动率预测
def volatility_forecast(returns, model, window=60):
    """
    使用时序模型预测未来波动率
    """
    # 计算已实现波动率
    rv = (returns**2).rolling(window).sum()
    rv = rv.dropna()
    
    # 预测
    forecast = model.predict(rv.values, prediction_length=22)
    
    return {
        'rv_forecast': forecast.mean(axis=0),
        'rv_std': forecast.std(axis=0)
    }
```

## 八、最佳实践

### 数据准备
```python
def prepare_timeseries_data(df, freq='D'):
    """
    准备时序数据
    """
    # 确保时间索引
    df['timestamp'] = pd.to_datetime(df['timestamp'])
    df = df.set_index('timestamp')
    
    # 重采样
    df_resampled = df.resample(freq).agg({
        'open': 'first',
        'high': 'max',
        'low': 'min',
        'close': 'last',
        'volume': 'sum'
    })
    
    # 处理缺失值
    df_resampled = df_resampled.ffill().bfill()
    
    return df_resampled
```

### 模型集成
```python
def ensemble_forecast(data, models):
    """
    多模型集成预测
    """
    forecasts = []
    
    for model in models:
        forecast = model.predict(data)
        forecasts.append(forecast)
    
    # 加权平均
    weights = [0.4, 0.3, 0.3]  # 可学习
    ensemble = np.average(forecasts, axis=0, weights=weights)
    
    return ensemble
```
