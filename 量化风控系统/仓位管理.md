## 一、Kelly公式基础理论

### 1.1 Kelly公式起源与数学推导
Kelly公式由John L. Kelly于1956年在《A New Interpretation of Information Rate》中提出。

**原始Kelly公式：**
f* = (bp - q) / b = p - q/b

其中：
- f* = 最佳下注比例（Kelly fraction）
- p = 获胜概率
- q = 失败概率 (q = 1 - p)
- b = 赔率（盈利/亏损的比例）

### 1.2 Kelly公式直观理解

| 场景 | Kelly公式 | 实际应用 |
|------|-----------|----------|
| 硬币游戏p=0.5, b=1 | f* = 0 | 不赌不赢不亏 |
| 硬币游戏p=0.6, b=1 | f* = 0.2 | 20%仓位 |
| 高优势策略p=0.55, b=2 | f* = 0.4 | 40%仓位 |
| 极高优势p=0.8, b=3 | f* = 0.73 | 73%仓位 |

### 1.3 Kelly公式Python实现

```python
import numpy as np
import pandas as pd

class KellyCriterion:
    """Kelly公式计算器"""

    @staticmethod
    def basic_kelly(p, b):
        q = 1 - p
        f = (p * b - q) / b
        return max(0, f)

    @staticmethod
    def gaussian_kelly(mu, sigma, rf=0):
        if sigma == 0: return 0
        kelly = (mu - rf) / (sigma ** 2)
        return max(0, kelly)

    @staticmethod
    def binary_outcome_kelly(win_rate, win_loss_ratio):
        p = win_rate; b = win_loss_ratio; q = 1 - p
        return max(0, (p * b - q) / b)
```

## 二、经典Kelly变体与改进

### 2.1 Half-Kelly与Quarter-Kelly
由于实际市场中参数估计存在误差，完整Kelly往往过于激进，常用Half-Kelly（50%）或Quarter-Kelly（25%）。

```python
class FractionalKelly:
    def __init__(self, fraction=0.5):
        self.fraction = fraction

    def get_kelly(self, p, b):
        q = 1 - p
        kelly = (p * b - q) / b
        return max(0, kelly * self.fraction)
```

### 2.2 边界Kelly（Bound Kelly）
- 最大仓位限制：min(kelly, max_position)
- 杠杆上限：min(kelly, 1/max_leverage)
- 波动率目标：target_vol / realized_vol

## 三、仓位管理策略

### 3.1 固定比例仓位管理
每次最多亏损账户的固定百分比（如2%）。

Position = Account * Risk% / StopLoss%

### 3.2 ATR仓位管理
基于平均真实波幅（ATR）计算止损距离。

Position = (Account * Risk%) / (ATR * Multiplier)

### 3.3 波动率仓位管理
根据历史波动率动态调整仓位。

Leverage = TargetVol / RealizedVol

### 3.4 风险平价策略
每个资产贡献相同的市场风险权重。

w_i = (1/sigma_i) / sum(1/sigma_j)

## 四、资金管理策略

### 4.1 固定本金管理
- 回撤20%时停止交易
- 回撤50%时重置账户50%

### 4.2 金字塔加仓策略
盈利时逐步加仓，仓位递减：
- 第一层: base_position
- 第二层: base_position * 0.8
- 第三层: base_position * 0.6

### 4.3 反金字塔减仓策略
使用追踪止损，回撤达到阈值时减仓。
回撤 >= 10% 时减仓5%

### 4.4 圣殿塔资金管理（Temple Tower）
根据连续胜负调整风险：
- 连续亏损>=2: 减少风险
- 连续盈利>=3: 增加风险（有上限）

## 五、实战案例与代码实现

### 5.1 综合Kelly仓位管理器

```python
import numpy as np

class KellyPositionManager:
    def __init__(self, initial_capital=1000000, kelly_fraction=0.5,
                 max_position_pct=0.25, max_drawdown=0.20):
        self.capital = initial_capital
        self.peak = initial_capital
        self.kelly_fraction = kelly_fraction
        self.max_position_pct = max_position_pct
        self.max_drawdown = max_drawdown
        self.trades = []

    def calculate_kelly(self, win_rate, win_loss_ratio):
        q = 1 - win_rate
        kelly = (win_rate * win_loss_ratio - q) / win_loss_ratio
        return max(0, min(kelly * self.kelly_fraction, self.max_position_pct))

    def calculate_position(self, entry_price, stop_loss_pct):
        if self.get_drawdown() >= self.max_drawdown:
            return 0
        risk = self.capital * 0.02 * self.kelly_fraction
        position = risk / (entry_price * stop_loss_pct)
        max_pos = self.capital * self.max_position_pct / entry_price
        return int(min(position, max_pos))

    def get_drawdown(self):
        return (self.peak - self.capital) / self.peak

    def update_trade(self, pnl):
        self.capital += pnl
        if self.capital > self.peak: self.peak = self.capital
        self.trades.append(pnl)
```

## 六、关键公式速查

### Kelly公式系列

| 公式 | 用途 |
|------|------|
| f* = (bp - q) / b | 基础Kelly |
| f* = E[R] / Var[R] | 高斯假设Kelly |
| G = p*ln(1+bf) + q*ln(1-f) | 期望增长率 |

### 仓位管理公式

| 公式 | 用途 |
|------|------|
| Position = Risk / ATR | ATR仓位 |
| Position = TargetVol / RealizedVol | 波动率仓位 |
| w_i = 1/sigma_i / sum(1/sigma_j) | 风险平价 |

### 风控阈值

| 指标 | 推荐值 |
|------|------|
| 单笔最大亏损 | 账户的1-2% |
| 日内最大亏损 | 账户的5% |
| 最大回撤 | 账户的20% |
| Kelly分数 | 0.25-0.5 |
