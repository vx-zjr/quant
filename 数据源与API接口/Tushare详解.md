# Tushare数据接口详解

## 一、平台概述

## 二、注册与Token获取

### 2.1 用户注册

1. 访问Tushare网站 https://tushare.pro ，点击右上角注册
2. 填写注册信息，确保手机号码和图形验证码正确后，点击获取验证码
3. 收到验证码后填写，完成后点击注册按钮

### 2.2 获取Token

1. 登录Tushare Pro网站
2. 进入个人中心，点击接口_TOKEN菜单
3. 复制Token字符串用于后续编程调用

### 2.3 Python连接示例

```python
import tushare as ts
ts.set_token(your_token_here)
pro = ts.pro_api()
df = pro.trade_cal(exch=SSE, start_date=20240101, end_date=20240110)
print(df)
```

## 三、积分体系详解

Tushare Pro采用积分制来管理用户权限，数据获取权限与积分直接挂钩。

### 3.1 积分说明

Tushare每个接口的积分门槛各不相同，数据成本非常高。获取权限一般有有效期，一旦过期不及时续费会失去权限。

### 3.2 积分获取方式

| 方式 | 说明 | 可获积分 |
|------|------|----------|
| 新用户注册 | 初始赠送 | 100分 |
| 成功推荐注册 | 推荐一个有效用户 | 50分 |
| 修改个人资料 | 完成邮箱绑定等 | 20分 |
| 登录打卡 | 每日首次登录 | 5-100分 |
| 提交BUG反馈 | 确认后奖励 | 5-50分 |
| 论坛互动 | 参与讨论回答问题 | 50-200分 |
| 社区贡献 | 分享策略、教程等 | 100-1000分 |
| 校企合作 | 加入高校计划 | 特定 |
| 专业微信群 | 加入5000人专业群 | 特定 |
| 高级用户QQ群 | 群号1059991854 | 200分 |
| 数据定制 | 联系客服付费 | 不等 |


### 3.3 积分扣除规则

| 情况 | 扣除积分 |
|------|----------|
| 注册后不登录 | 不扣分 |
| 成功推荐一个有效用户 | 获得50分（从推荐人扣除） |
| 登录超时中断 | 100-500分 |
| 频繁访问超限 | 50-500分 |
| 提交无效数据定制 | 50-500分 |

## 四、数据获取方式

pro = ts.pro_api(your_token)

通过HTTP POST请求直接获取JSON格式数据。

## 六、主要API接口详解

### 6.1 股票基础信息

- 获取股票列表: pro.stock_basic(exchange=, list_status=L)
- 获取公司信息: pro.stock_company(ts_code=000001.SZ)
- 获取IPO新股列表: pro.new_share(start_date=20240101, end_date=20240131)

### 6.2 K线数据

- 日线数据: pro.daily(ts_code=000001.SZ, start_date=20240101, end_date=20240131)
- 周线数据: pro.weekly(ts_code=000001.SZ, start_date=20230101, end_date=20240101)
- 月线数据: pro.monthly(ts_code=000001.SZ, start_date=20230101, end_date=20240101)

### 6.3 财务数据

- 利润表: pro.income(ts_code=000001.SZ)
- 资产负债表: pro.balancesheet(ts_code=000001.SZ)
- 现金流表: pro.cashflow(ts_code=000001.SZ)

### 6.4 实时行情

- 实时行情: pro.daily_basic(ts_code=, trade_date=20240102)

## 八、平台管理说明

### 8.1 权限等级

用户需要通过积分来解锁不同的数据权限。积分越高，可访问的数据范围越广、频率限制越宽松。

### 8.2 权限说明

数据接口的权限是一套有有效期的机制，一旦过期不及时续费就会失去权限。

### 8.3 注意事项

1. Tushare每个接口的积分门槛各不相同
2. 获取权限一般有有效期限制
3. 及时续费以保持权限有效
4. 频繁访问可能触发限流
5. 建议用户根据自身需求选择合适的积分等级
