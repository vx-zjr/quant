## 1. 机器学习基础课程  
  
### 吴恩达Machine Learning  
- 平台: Coursera  
- 费用: 免费（可申请助学金） 
- 难度: 初级至中级  
- 优点: 机器学习入门经典；概念清晰；代码示例详细  
- 缺点: 偏理论；缺少量化专题  
- 推荐指数: 5星  
  
### 斯坦福CS229  
- 平台: Stanford OpenEdX  
- 费用: 免费  
- 难度: 中高级  
- 优点: 斯坦福标准课程；数学推导严谨  
- 推荐指数: 5星

## 2. 深度学习课程  
  
### 吴恩达Deep Learning Specialization  
- 平台: Coursera

### Fast.ai 深度学习课程

- 费用: 免费

- 推荐指数: 4星

## 3. ML量化专业书籍  
  
### Advances in Financial Machine Learning  
- 作者: Marcos Lopez de Prado  
- 费用: 约400元  
- 难度: 高级  
- 优点: ML量化必读；包含大量实践技巧；讨论过拟合问题  
- 缺点: 难度较高；需要一定基础  
- 推荐指数: 5星  
  
### Machine Learning for Algorithmic Trading  
- 作者: Stefan Jansen  
- 费用: 约500元  
- 难度: 中级  
- 优点: 代码驱动；实操性强；覆盖完整  
- 推荐指数: 5星  
  
### Artificial Intelligence in Finance  
- 作者: Yves Hilpisch  
- 费用: 约400元  
- 难度: 中级  
- 优点: Python实现AI金融应用；强化学习部分实用  
- 推荐指数: 4星
