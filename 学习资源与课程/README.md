## 五、量化学习路径

### 入门阶段(0-6个月)
```
第1-2月: Python基础
├── 廖雪峰Python教程
├── 《Python编程从入门到实践》
└── LeetCode简单题100道

第3-4月: 金融基础
├── 《金融市场基础知识》
├── 《证券从业资格考试》
└── 雪球/集思录实战贴

第5-6月: 量化入门
├── 聚宽/米筐入门教程
├── Backtrader回测入门
└── 编写第一个简单策略
```

### 进阶阶段(6-12个月)
```
第7-8月: 机器学习
├── 吴恩达ML课程
├── sklearn官方文档
└── XGBoost/LightGBM

第9-10月: 深度学习
├── Fast.ai课程
├── PyTorch入门
└── LSTM时序预测

第11-12月: 实盘准备
├── vnpy框架学习
├── 模拟盘实操
└── 券商API对接
```

### 高阶阶段(1-2年)
```
研究方向:
├── 多因子模型
├── NLP舆情分析
├── 强化学习交易
└── 高频交易

技术方向:
├── C++高性能开发
├── FPGA加速
├── 分布式系统
└── 机器学习平台
```
