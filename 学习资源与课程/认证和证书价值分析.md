## 1. 国际认证  
  
### CQF（量化认证证书）  
- 费用: 约18,000美元  
- 时长: 6个月  
- 价值: 量化领域国际认可度最高  
- 优点: 课程前沿；师资强大；校友网络广  
- 缺点: 价格昂贵；不是学位  
- 适合人群: 想转型量化的金融从业者  
  
### CFA（特许金融分析师）  
- 费用: 约4,500美元（三级） 
- 时长: 通常3年  
- 价值: 金融领域最权威认证  
- 优点: 全球认可；系统金融知识；职业发展  
- 缺点: 非专门量化；传统内容多  
- 适合人群: 资产管理行业从业者 
  
  
### FRM（金融风险管理师）  
- 费用: 约1,500美元  
- 时长: 1-2年  
- 价值: 风险管理领域权威认证  
- 适合人群: 风控岗位从业者

## 2. 国内认证  
  
### AQF（量化金融分析师）  
- 机构: 中国量化投资学会  
- 费用: 约15,000元  
- 时长: 6个月  
- 价值: 国内量化认证；实用性较强  
- 优点: 中文授课；国内资源对接  
- 缺点: 国际认可度较低  
  
### 证券从业资格  
- 费用: 低  
- 价值: 国内从业基本要求  
- 推荐指数: 3星（有精力就考）
