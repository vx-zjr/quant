| 项目 | 内容 |
|------|------|

| 出版 | 2000年(第1版) |
| 难度 | ★★★★ |
| 评价 | 量化投资圣经 |

## 八、书籍阅读顺序建议

### 入门阶段
```
第1阶段: 基础概念
├── 《金融市场技术分析》- 技术分析入门
├── 《海龟交易法则》- 系统交易
├── 《量化交易》Ernest Chan - 量化入门
└── 《Python for Data Analysis》- 编程基础
```

### 进阶阶段
```
第2阶段: 量化理论
├── 《主动投资组合管理》- 量化圣经
├── 《统计学习方法》- ML基础
├── 《期权、期货及其他衍生品》- 期权基础
└── 《风险价值的计算》- 风控基础
```

### 高阶阶段
```
第3阶段: ML量化
├── 《Advances in Financial ML》- ML量化必读
├── 《Machine Learning for Algorithmic Trading》- 实战
├── 《Artificial Intelligence in Finance》- AI应用
└── 《金融工程手册》- 百科全书
```

### 思想升华
```
第4阶段: 思想与视野
├── 《黑天鹅》- 风险哲学
├── 《The Man Who Solved the Market》- 传奇故事
└── 《More Money Than God》- 行业历史
```
