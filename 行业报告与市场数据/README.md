## 七、数据质量评估

1. 覆盖度：市场、品种、字段、历史长度是否够。
2. 时效性：日频、分钟、实时数据的延迟和稳定性。
3. 准确性：复权、停牌、涨跌停、财报发布日期是否可靠。
4. 完整性：缺失值、异常值、退市股票、指数成分变更。
5. 一致性：同一字段在不同数据源之间是否冲突。

## 八、个人起步的数据路线

1. 用 `AKShare` 或 `Tushare` 获取A股日线、指数、交易日历、基础财务指标。
2. 先做日频策略，不碰高频和实时交易。
3. 建立最小数据表：价格、复权因子、成交额、市值、行业、指数成分。
4. 每读一篇因子研报，只复现一个最小因子，例如动量、反转、波动率、换手率、市值。
5. 重点记录：样本区间、调仓频率、交易成本、年化收益、最大回撤、换手率、IC/RankIC。
