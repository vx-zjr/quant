## 一、Renaissance Technologies (大奖章基金)

### 基本信息
| 项目 | 内容 |
|------|------|
| 简称 | RenTech |
| 总部 | 纽约州东锡托基特 |
| 创始人 | Jim Simons |
| 成立时间 | 1982年 |

### 核心数据
| 指标 | 数值 |
|------|------|
| 管理规模 | ~600亿美元(大奖章) |
| 年化收益 | ~66%(大奖章) |
| 员工人数 | ~300人 |

### 投资策略
- **Medallion基金**: 仅对内部员工开放
- 纯量化、统计套利
- 短期持仓(分钟到天)
- 高频数据处理

### 成功要素
1. **顶尖人才**: 诺贝尔奖得主、数学家
2. **数据驱动**: 海量数据处理能力
3. **保密文化**: 策略高度保密
4. **技术基础设施**: 自研交易系统

### 传奇人物: Jim Simons
- 数学家，菲尔兹奖得主
- 陈省身-西蒙斯理论创立者
- 量化投资之父
