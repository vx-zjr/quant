### 国内行业趋势

- 头部化加速：2021年前后约10家百亿量化，2023年前后扩展到约30家，2024-2025继续增加。
- 策略主线：指数增强仍是主流，单一策略向多策略组合迁移。
- 技术竞争：AI大模型、另类数据、低延迟交易系统、自动化因子挖掘成为投入重点。
- 国际化：头部机构开始吸收海外量化经验，布局海外市场和国际化人才。

## 七、学习路线提炼

1. 先看国内头部私募：理解指增、Alpha、CTA、多策略、市场中性。
2. 再看国际机构：理解统计套利、做市、高频、平台化研究。
3. 补技术主线：机器学习、因子挖掘、低延迟系统、另类数据。
4. 补求职主线：数学+编程+策略研究，国内重实习产出，国际重算法和数学思维。
