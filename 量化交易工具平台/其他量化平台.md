## 一、RiceQuant 米筐

### 平台概览

| 项目 | 内容 |
|------|------|
| 平台名称 | RiceQuant 米筐量化 |
| 官方网站 | https://www.ricequant.com |
| 成立时间 | 2015年 |
| 公司背景 | 深圳米筐科技有限公司 |
| 平台定位 | 专业的量化策略研究与交易平台 |

RiceQuant（米筐科技）成立于2015年，是国内最早的量化投资研究平台之一。
### 核心功能

#### 1. 策略研究环境
| 功能 | 描述 |
|------|------|
| Web IDE | 基于浏览器的在线策略编辑器 |
| Jupyter Notebook | 交互式研究环境 |
| 策略模板 | 丰富的策略模板库 |
| 代码分享 | 策略代码云端保存与分享 |

#### 2. 回测引擎
| 功能 | 描述 |
|------|------|
| 回测频率 | 支持 Tick、分钟、小时、日、周级别 |
| 回测速度 | 高性能事件驱动回测引擎 |
| 持仓分析 | 详细持仓记录与分析 |
| 收益归因 | 多维度收益分解 |
| 风险指标 | 夏普比率、最大回撤、卡玛比率等 |

#### 3. 实盘交易
| 功能 | 描述 |
|------|------|
| 券商对接 | 支持多家主流券商 |
| 自动交易 | 策略信号自动执行 |
| 风控管理 | 内置风控模块 |
| 持仓同步 | 实盘持仓实时同步 |

#### 4. 数据服务
| 数据类型 | 覆盖范围 |
|----------|----------|
| A股数据 | 全市场历史行情、财务数据 |
| 期货数据 | 商品期货、金融期货 |
| 期权数据 | 股票期权、商品期权 |
| 基金数据 | 公募基金、ETF |
| 指数数据 | 主要宽基、行业指数 |
| 宏观数据 | 经济指标、利率、汇率 |

### AI写策略功能（特色功能）

RiceQuant是国内首家推出AI写策略功能的量化平台，用户可以通过自然语言描述策略思路，系统自动生成Python代码。

输入示例：近5日涨幅前10且换手率>5%的股票

系统处理流程：
1. 自然语言理解 - 识别选股条件
2. 规则映射 - 生成筛选逻辑
3. 代码生成 - 输出Python代码
4. 回测验证 - 一键回测验证

### 收费体系

| 版本 | 价格 | 主要权益 |
|------|------|----------|
| 免费版 | 免费 | 基础回测、模拟交易 |
| 专业版 | 99元/月 | 快速回测、完整数据 |
| 旗舰版 | 299元/月 | 全功能、数据全面 |
| 机构版 | 定制 | 专属服务、技术支持 |

### 优势与特点

- AI赋能：国内首创AI写策略功能，降低量化门槛
- 数据质量：高质量历史数据，数据更新及时
- 回测速度：高性能回测引擎，回测速度快
- 社区氛围：活跃的策略分享社区

### 适用人群

- 量化入门学习者
- 策略研究爱好者
- 专业量化投资者
- 量化交易初创团队

### 因子库特色

优矿的因子库是其核心优势之一：

技术面因子：动量类因子（收益率、累计收益率、波动率）、趋势类因子（MA均线偏离度、MACD、RSI）、成交量类因子（换手率、量价相关性、成交量变化率）

基本面因子：估值类因子（PE市盈率、PB市净率、PS市销率）、成长类因子（营收增长率、利润增长率、资产增长率）、盈利类因子（ROE净资产收益率、ROA资产收益率、毛利率）

市场情绪因子：资金流因子、龙虎榜因子、分析师预期因子
