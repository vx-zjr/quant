### 策略示例
```python
# 聚宽示例策略
from jqdata import *

def initialize(context):
    g.stock = '000001.XSHE'
    g.amount = 100

def handle_data(context, data):
    # 双均线策略
    ma5 = data[g.stock].mavg(5, 'close')
    ma20 = data[g.stock].mavg(20, 'close')
    
    if g.stock not in context.portfolio.positions:
        if ma5 > ma20:
            order_target(g.stock, g.amount)
    else:
        if ma5 < ma20:
            order_target(g.stock, 0)
```

- 完全开源免费
- 社区活跃
- 文档完善
- 支持多种券商

### 架构
```
┌─────────────────────────────────┐
│         应用层 (策略/UI)         │
├─────────────────────────────────┤
│         策略引擎                 │
├─────────────────────────────────┤
│         风控模块                 │
├─────────────────────────────────┤
│       数据服务/交易服务          │
├─────────────────────────────────┤
│         接口层 (CTP/期货等)      │
└─────────────────────────────────┘
```

### 入门示例
```python
from vnpy.app.quantitativeTrading import *
from vnpy.app.strategy_demo import *

# 创建策略引擎
engine = QuantitativeTradingEngine()
engine.add_strategy(StrategyDemo())

# 运行
engine.run()
```
