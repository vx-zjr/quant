## 七、会议论文搜索示例

### 搜索策略
```python
# 使用Semantic Scholar API搜索论文
import requests

def search_quant_papers(query, limit=10):
    """
    搜索量化相关论文
    """
    url = "https://api.semanticscholar.org/graph/v1/paper/search"
    params = {
        "query": query,
        "fields": "title,authors,abstract,year,citationCount,venue",
        "limit": limit
    }
    headers = {"x-api-key": "YOUR_API_KEY"}
    
    response = requests.get(url, params=params, headers=headers)
    return response.json()

# 搜索示例
# 搜索LLM金融应用
papers = search_quant_papers("large language model finance", limit=20)
# 搜索时序预测
papers = search_quant_papers("time series foundation model", limit=20)
```

### 阅读顺序
1. **摘要** - 判断论文是否值得阅读
2. **结论** - 了解论文贡献
3. **图表** - 快速理解方法
4. **实验** - 验证方法有效性
